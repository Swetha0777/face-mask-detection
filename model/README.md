# Model Directory

This directory stores trained deep learning models and training evaluation artifacts for the **Face Mask Detection** application.

## Stored Artifacts

- `face_mask_detector.keras`: Trained deep learning model saved in Keras native format (MobileNetV2 / CNN architecture).
- `metrics.json`: JSON metadata containing training accuracy, validation accuracy, loss progression, and timestamp.
- `confusion_matrix.png`: Saved plot of model confusion matrix generated by `evaluate.py`.
- `evaluation_report.json`: JSON report containing precision, recall, and F1-score breakdown.

## Usage

To generate or update the model file:

```bash
python train.py
```

To evaluate model metrics:

```bash
python evaluate.py
```
